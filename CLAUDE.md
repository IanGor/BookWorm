# BookWorm

Личная читалка FB2/EPUB для Android с собственным движком вёрстки уровня Kindle.
Полная спецификация и все принятые решения — [docs/SPEC.md](docs/SPEC.md). Читать перед любой работой.
Текущий этап, на чём остановились и что делать первым — [docs/STATUS.md](docs/STATUS.md).

Ключевые правила:
- Эталон для спорных решений — электронная книга Kindle. Настроек не добавлять без явного запроса.
- Вёрстка делается в ядре `bookworm-core` (Rust), а не текстовым стеком Android. Android только рисует готовые глифы.
- Ядро должно собираться и тестироваться на компьютере (`bw-render` → PNG), без телефона.
- Тестовый корпус: `tests/corpus/` (описание случаев — `tests/corpus/README.md`). Генератор синтетики — `tools/gen_corpus.py`.
- Язык документации и интерфейса — русский.
