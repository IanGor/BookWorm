# Тестовый корпус

- `synthetic/` — сгенерированные файлы, каждый нацелен на свой класс трудностей.
  Пересоздать: `python3 tools/gen_corpus.py` (нужен ImageMagick).
- `real/` — настоящие книги из общественного достояния: `python3 tools/real_corpus.py` скачивает их сюда для замеров (`examples/spacing.rs`). В репозиторий не входят.

Входной текст в синтетике намеренно «грязный»: прямые кавычки, дефисы вместо тире, `...`,
двойные пробелы. Так выглядят реальные книги после конвертеров. Ожидаемый результат описан ниже.

## Что проверяет каждый файл

### 01_typography_ru.fb2 — типограф
Каждый случай — отдельный раздел с заголовком.

| Случай | Ожидается |
|--------|-----------|
| Многоточия | `...` → `…`; `?..` `!..` `?!.` сохраняются; `. . .` → `…`; `……` и `....` → `…` |
| Кавычки | внешние «ёлочки», вложенные „лапки“; уже правильные не трогаются; `"` внутри «» становятся „“; апострофы `’` |
| Тире | ` - ` и ` -- ` → неразрывный пробел + `—`; реплика `- Ты` → `— Ты` с неразрывным пробелом; `1812-1814` → `1812–1814`; слова через дефис (`кто-нибудь`) не трогаются; тире не начинает строку |
| Числа и сокращения | неразрывные пробелы: `1812 г.`, `2500 км`, `№ 5`, `§ 3`, `т. е.`, `и т. д.`, `10 000`; `№12` → `№ 12` |
| Инициалы | `А. С. Пушкин` не разрывается между строками; `А.С.` получает неразрывные пробелы |
| Короткие слова | ни одна строка не заканчивается на `в`, `и`, `а`, `к`, `с`, `у`, `о` |
| Длинные слова | переносятся по словарю, минимум 2 буквы до и после переноса, не больше 2 переносов подряд; составные — только по дефису |
| Ё и ударения | ё сохраняется; знак ударения U+0301 стоит точно над гласной, не ломает переносы и кернинг |
| Невидимые символы | двойные пробелы и табы схлопываются; неразрывный пробел держит слова; пробел нулевой ширины — место возможного разрыва; мягкий перенос — разрешённая точка переноса; `\n` внутри абзаца = пробел |
| Латиница | слова с латинской буквой внутри кириллицы не ломают переносы; французский и немецкий не переносятся по русским словарям; английские фразы — по английским |
| Ссылки | URL и путь не переносятся по слогам, разрываются только после `/`, `_`, `\`, `.` без знака переноса |
| Разметка | курсив и жирный внутри слова не разрывают слово; `sup`/`sub` уменьшены и смещены, не раздвигают строки; моноширинный код не растягивается |

### 02_structure_ru.fb2 — структура FB2
- Заголовок книги из двух `<p>`, обложка, серия, аннотация.
- Заголовки 1–4 уровня разного кегля; заголовок из двух строк.
- Эпиграф (абзац + автор справа), эпиграф со стихотворением.
- Стихи: строфы с интервалом, автор и дата; продолжение длинной строки начинается от общего левого края строфы.
- `cite` с двумя абзацами и автором, `empty-line`, `subtitle` `* * *` по центру.
- Картинки: широкая (по ширине), высокая (целиком на странице, не режется),
  прозрачная с чёрными линиями (видна в ночной теме), внутристрочная, почти полностраничная серая.
- Таблица с `th`, `colspan`, `align`, переносом текста в ячейке.
- Сноски: короткая, длинная (4 абзаца, попап с прокруткой или кнопкой «Перейти»),
  сноска на сноску, сноска со стихами, повторная ссылка на ту же сноску, комментарий из `body name="comments"`.
  Тело `notes` не выводится в основном потоке.
- Пустая глава не ломает оглавление и разбиение на страницы.

### 05_pagination_ru.fb2 — разбиение на страницы
40 разделов со случайной, но фиксированной (seed) структурой: абзацы из одного слова,
абзацы длиннее страницы, строфы до 12 строк, подзаголовок сразу после заголовка, вложенные подразделы.
Проверять:
- нет висячих строк (одна строка абзаца вверху или внизу страницы);
- заголовок не стоит последним на странице, за ним минимум 2 строки;
- нижняя строка всех полных страниц на одной высоте (сетка строк);
- каждый раздел верхнего уровня начинается с новой страницы;
- строфа не разрывается без необходимости.

### 06_english_epub3.epub — EPUB3 на английском
- Навигация `nav.xhtml` с вложенностью, обложка SVG в `cover.xhtml` (`linear="no"`), примечания `linear="no"`.
- Сноска `aside epub:type="footnote"` в том же файле — не видна в потоке, только в попапе;
  концевые примечания в отдельном файле; ссылки назад `↩`.
- Английская типографика: “ ” ‘ ’, апострофы `’90s`, `rock ’n’ roll`, `--` → `—`, `1914–1918`, `. . .` → `…`.
- Лигатуры fi, fl, ff, ffi, ffl.
- CSS издателя с мусором: `font-family`, `12pt`, `line-height`, цвета, фон, `48px`, отсутствующий `@font-face` —
  всё игнорируется; `display:none` скрывает абзац; `small-caps`, буквица, `text-align`.
- `blockquote` с атрибуцией, `hr` и `* * *`, списки (вложенные), таблица, `pre` (без выключки),
  длинный URL, абзац `lang="ru"` внутри английской книги (русские переносы и кавычки).
- Стихи через классы CSS с отрицательным `text-indent`, `figure` + `figcaption` (держатся вместе).

### 07_epub2_calibre.epub — EPUB2 после Calibre, на русском
- Оглавление только NCX, пункты ведут на якоря внутри одного файла.
- Заголовки не тегами, а `<p class="title">`; курсив и жирный — классами CSS.
- Сущности `&nbsp; &mdash; &hellip; &laquo;` (DTD XHTML 1.1, без сети).
- Сноска EPUB2: обычная ссылка в другой файл без `epub:type`; распознаётся эвристикой.
- Стихи через `<br/>`, текст прямо в `div` и в `body`, пустой абзац из пробелов.
- Обложка через `<meta name="cover">`, серия из `calibre:series`.

### 08_big_ru.fb2 — производительность
5,7 МБ, 200 глав. Открытие на сохранённой позиции < 1 с, полная раскладка в фоне.

### 09_broken.fb2 — сломанный файл
BOM и пробелы перед XML-декларацией, неэкранированный `&`, неизвестные теги, `xlink:` вместо `l:`,
ссылка на несуществующую сноску, отсутствующий бинарник, незакрытый `<p>`, атрибут без кавычек,
пустые разделы, дубликат `id`, `<lang>RU</lang>`.
Ожидается: книга открывается, текст показан, проблемные места пропущены без падения.

### 10_calibration.fb2 / 10_calibration.epub — сравнение с Kindle
Одинаковый текст в двух форматах. EPUB отправляется на Kindle через Send to Kindle,
снимаются скриншоты при стандартных настройках (Bookerly, размер по умолчанию, поля по умолчанию).
Наш рендер той же главы сравнивается с ними: поля, кегль, интервал, отступ абзаца, переносы, заголовок, эпиграф.
