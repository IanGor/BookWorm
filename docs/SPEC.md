# BookWorm — спецификация

Личная читалка FB2/EPUB для Android с типографикой уровня Kindle.
Эталон для любого спорного решения — электронная книга Kindle (e-ink, не приложение).
Принцип: открыл — читаешь. Настроек минимум.

## 1. Зафиксированные решения

## 2. Архитектура

```
┌──────────────────────── Android-приложение (Kotlin) ────────────────────────┐
│  Библиотека · Экран чтения · Оглавление · Сноска-попап · Настройки          │
│  ReaderView: рисует список отрисовки через Canvas.drawGlyphs (API 31+)      │
└───────────────────────────────▲─────────────────────────────────────────────┘
                                │ UniFFI / JNI, страница = компактный бинарный буфер
┌───────────────────────────────┴──── bookworm-core (Rust) ───────────────────┐
│ formats/  fb2, epub (OCF, OPF, NCX/nav, XHTML), кодировки, zip              │
│ model/    общее дерево документа: блоки и инлайны со смыслом                 │
│ style/    стилевая тема «как Kindle» + подмножество CSS книги               │
│ typo/     типограф: кавычки, тире, многоточия, неразрывные пробелы          │
│ shape/    rustybuzz (HarfBuzz): кернинг, лигатуры, OpenType                 │
│ hyph/     переносы Лианга по словарям TeX (ru, en)                          │
│ break/    разбиение абзаца на строки по Кнуту — Плассу                      │
│ paginate/ страницы: сетка строк, висячие строки, заголовки, картинки        │
│ render/   список отрисовки страницы; растеризация в PNG (только для тестов) │
│ position/ стабильные позиции в книге, не зависящие от шрифта и размера      │
└──────────────────────────────────────────────────────────────────────────────┘
        ▲
        └── bw-render (CLI на компьютере): книга → PNG страниц + JSON-раскладка
            для эталонных тестов и сравнения со скриншотами Kindle
```

Ядро не знает об Android. Шрифты всегда берутся из файлов, которые поставляет приложение
или выбирает пользователь, поэтому раскладка детерминирована и одинакова на компьютере и телефоне.

### 2.1. Модель документа

Блоки: `Heading(level)`, `Subtitle`, `Paragraph`, `Epigraph`, `Cite`, `TextAuthor`,
`Poem → Stanza → Verse`, `Image`, `Table` (упрощённо), `SceneBreak`, `EmptyLine`, `Code`.
Инлайны: `Emphasis`, `Strong`, `SmallCaps`, `Sup`, `Sub`, `Strike`, `Code`, `NoteRef`, `Link`, `InlineImage`.
Каждый узел несёт язык (`ru`/`en`), который наследуется от книги, раздела или атрибута `lang`.

Позиция в книге: `(spine_index, block_path, char_offset)`. Не зависит от шрифта,
размера и геометрии экрана, поэтому место чтения сохраняется при смене настроек.

### 2.2. Стили

Своя стилевая тема по образцу Kindle задаёт всё по умолчанию. Из CSS книги берём:
`font-style`, `font-weight`, `font-variant: small-caps`, `text-align`, `text-indent`,
`margin-*` в `em` (с ограничением сверху), относительный `font-size` заголовков (с ограничением),
`vertical-align: super/sub`, `page-break-before/after`, `display: none`.
Игнорируем: `font-family`, абсолютные размеры, цвета, `line-height` (сетку строк задаём сами), фоны.

### 2.3. Типограф (до вёрстки, по языку узла)

Русский:
- `...` → `…`; `?..`, `!..` сохраняются; `. . .` → `…`
- `"…"` → «…», вложенные → „…“; апострофы → `’`
- ` - `, ` -- `, `—` между словами → неразрывный пробел + `—` + обычный пробел
- Тире в начале реплики диалога → `—` + неразрывный пробел
- Числовые диапазоны `1990-1995` → `1990–1995`
- Неразрывные пробелы: после однобуквенных и коротких предлогов/союзов
  (в, к, с, у, о, и, а, на, по, за, из, от, до, не, ни), в инициалах, после `№` и `§`,
  перед единицами измерения, в сокращениях `т. е.`, `и т. д.`
- Чистка: повторные пробелы, табы, пробелы нулевой ширины, пустые абзацы-разделители
- Знаки ударения U+0301 сохраняются и корректно позиционируются шейпингом

Английский: “ ” ‘ ’, апострофы (`’90s`, `rock ’n’ roll`), `--` → `—` без пробелов,
диапазоны → `–`, `. . .` → `…`.

### 2.4. Переносы

Словари hyph-utf8 (TeX) для `ru` и `en-us`. Правила:
- минимум букв до/после переноса: ru 2/2, en 2/3
- не больше двух переносов подряд
- нет переноса в последней строке абзаца и в последней строке страницы
- нет переносов в заголовках, URL, словах с цифрами
- слова через дефис переносятся только по дефису
- мягкие переносы из исходника имеют приоритет

### 2.5. Разбиение на строки

Кнут — Пласс (глобальная оптимизация абзаца) с узлами box/glue/penalty. Цель — как в печатной книге:
расстояния между словами почти одинаковы во всех строках, а ширину строки добирают переносы.
- Межсловный пробел — от 0,8 до 1,25 обычного (ширина пробела из шрифта).
- Микротипографика: остаток недостачи ширины делится по всем буквам строки — масштаб глифа по ширине
  до ±3 % и межбуквенный интервал до +2 % / −1 % кегля (как microtype в pdfTeX и glyph scaling в InDesign).
  Сначала все упругие элементы пропорционально; что сверх их предела — пробелам.
- Некрасивость строки считается по растяжению именно пробелов: алгоритм предпочитает перенос раздутым пробелам.
- Проходы: допуск 1 (всё в пределах), 2,5, затем аварийный; аварийное растяжение не занижает оценку строки.
- Моноширинный код не растягивается.
- Строка с одним-двумя пробелами, которую пришлось бы растянуть больше чем вдвое, ставится влево
  (неровный край одной строки лучше дыры в полстроки).
- Цитата (`cite`, `blockquote`): короткий абзац (до 100 знаков) без знака конца предложения — запись, подпись,
  формула — набирается флагом влево, без красной строки и переносов.
- Слова заглавными от 8 букв переносятся; короче — считаются аббревиатурами и не переносятся.
- последняя строка: не короче ~1/5 ширины, если это не стоит лишних переносов
- позже: висячая пунктуация (вынос кавычек, тире, точек и запятых в поле)

Замер — `cargo run --release -p bookworm-core --example spacing` на настоящей прозе (`python3 tools/real_corpus.py` скачивает тексты из общественного достояния в `tests/corpus/real`, в репозиторий они не входят):
доля выключенных строк с пробелом шире 1,25 обычного. На ступени 46: Literata 4 %, PT Serif 2 %,
Charis SIL 2 %, PT Sans 1 %, Bookerly 4 % (до переделки — 64–83 %). На крупных ступенях строка короче
25 знаков, и ровной её не сделать ничем: 12–20 % на ступени 62, 18–34 % на ступени 76.

### 2.6. Геометрия страницы и разбиение на страницы

- Левое и правое поля равны. Верхнее и нижнее поля равны (строка статуса внизу лежит в поле,
  сверху ей соответствует такая же пустая зона).
- Основной текст стоит на сетке строк. Высота текстового блока — целое число строк;
  остаток высоты делится поровну сверху и снизу. Поэтому последняя строка полной
  страницы всегда на одной и той же высоте.
- Заголовки, эпиграфы, стихи и картинки занимают целое (или кратное половине) число строк сетки.
- Висячие строки: минимум 2 строки абзаца внизу и вверху страницы. Если правило сработало,
  страница заканчивается на строку раньше (как у Kindle), а не растягивается.
- Заголовок не остаётся в конце страницы: за ним минимум 2 строки текста.
- Новая глава (раздел верхнего уровня, файл spine) начинается с новой страницы с отступом сверху.
- Строфы стихов по возможности не разрываются.
- Продолжение длинной строки стиха начинается от того же левого края, что и остальные строки строфы,
  без дополнительного отступа при переносе.
- Картинка вписывается в страницу целиком с сохранением пропорций, подпись — вместе с ней.

### 2.7. Отрисовка

Ядро отдаёт для страницы список: прогоны глифов (шрифт, размер, glyph id, x, y),
линии, прямоугольники, картинки, области ссылок (для сносок).
На телефоне рисуем через `Canvas.drawGlyphs` с `android.graphics.fonts.Font`, загруженным
из того же файла, которым пользовалось ядро. Растеризацией и сглаживанием занимается Skia.
На компьютере `bw-render` растеризует то же самое в PNG.

### 2.8. Размер шрифта и смена гарнитуры

Цель — типографика печатной книги при любой гарнитуре и любом размере.
- Поля зависят только от экрана: ни шрифт, ни размер их не меняют.
- Ступень размера задаёт **высоту строчных**, а не кегль: кегль гарнитуры = ступень × 0,536 / её высота строчных
  (0,536 — Noto Serif, опорная). Поэтому при смене гарнитуры плотность текста почти не меняется.
- Шаг строк = 1,4 × ступень и не зависит от гарнитуры: число строк на странице при смене шрифта то же самое,
  текст стоит на сетке.
- Разрядки (трекинга) в основном тексте нет; выключка — межсловными пробелами (Кнут — Пласс) и переносами,
  кернинг, лигатуры и ширина пробела — из самого шрифта.
- Вариативные шрифты (ось `wght`): обычное и жирное начертания берутся из одного файла.
- Бионическое чтение (по образцу пользователя): выделяется первая треть букв каждого слова
  с округлением вверх. В вариативных шрифтах — Semibold (`wght=600`), в статических — доступное
  жирное начертание. Цвет текста не меняется. Слово считается до переноса строк, включая мягкие
  переносы; комбинируемые знаки ударения не считаются отдельными буквами. Курсив сохраняется,
  авторский жирный, код, индексы и знаки сносок не меняются. Строка статуса остаётся обычной.
- Ступени: 30, 34, 38, 42, **46**, 51, 56, 62, 68, 76, 84 px при ширине 1080. Строка статуса от размера не зависит.

### 2.9. EPUB

OCF → OPF (метаданные, манифест, spine) → XHTML по порядку spine; каждый файл с новой страницы,
нелинейные (`linear="no"`) в поток не идут. Оглавление: `nav` (EPUB 3), иначе NCX, иначе заголовки.
CSS книги — подмножество из §2.2: селекторы тег/класс/id и потомки, остальные пропускаются.
Сноски: `epub:type="noteref"` или короткая ссылка («1», «*», «[2]») на элемент с id; `aside` со сноской
в поток не попадает; ссылки «назад» в сноске убираются. Эвристики Calibre: `<p class="title">` с крупным
жирным шрифтом — заголовок (и абзацы внутри такого `div`), класс `epigraph` — эпиграф, `poem`/`stanza` — стихи, подпись под эпиграфом — автор. Конвертеры из FB2: строчный элемент с абзацами внутри — контейнер,
`<p class="empty-line"/>` — пустая строка, сноска — `<span id>` с номером и абзацем.

## 3. Производительность

- Первая страница при запуске — сразу: верстается только глава с сохранённой позицией.
- Полная раскладка книги (для процентов и времени до конца главы) — в фоне, кэшируется на диске
  по ключу `(книга, шрифт, размер, геометрия)`.
- FB2 размером в несколько мегабайт должна открываться меньше чем за секунду.

## 4. Интерфейс

Экран чтения (системные панели скрыты):
- касание в верхней трети экрана — назад; в нижней трети — вперёд
- касание в центральной трети по обеим осям — меню: библиотека, оглавление, «Аа» (шрифт и размер), тема;
- долгое нажатие на абзац — выделение текста и комментарий об ошибке оформления, экспорт
  TXT-промпта с полным абзацем, соседями, стилями, настройками и фактической разбивкой на строки;
  боковые области средней трети не листают и не открывают меню
- вместе с меню появляется системная строка состояния (часы, сеть, батарея), при закрытии меню скрывается;
  верхняя панель учитывает высоту строки состояния и выреза, страница остаётся на месте
- свайп влево/вправо — вперёд/назад; кнопки громкости — вниз вперёд, вверх назад
- касание по знаку сноски — попап снизу с текстом сноски (свёрстанным тем же движком)
  и кнопкой «Перейти»
- внизу слева: «N мин до конца главы» (скорость чтения вычисляется по реальному чтению);
  внизу справа: процент книги


Оглавление: дерево глав, текущая выделена, переход по касанию.

Библиотека: сетка обложек, сортировка по последнему открытию. Импорт через «Открыть с помощью» / «Поделиться»
и кнопку «+» (системный выбор файла). Файл копируется во внутреннее хранилище приложения. Удаление книги.

Настройки (меню → «Настройки»):
- шрифт: встроенные (Literata — по умолчанию, PT Serif, Charis SIL, PT Sans)
  + свои: «Свои шрифты: выбрать папку…» открывает системный «Обзор», TTF/OTF из папки
  (и вложенных) копируются в приложение и появляются в списке с пометкой «свой»;
  гарнитура без кириллицы помечена
- размер: ступени кнопками A− / A+ или вертикальным свайпом по левому краю экрана (вверх — крупнее), книга переверстывается сразу (§2.8)
- бионическое чтение: выключено / включено, по умолчанию выключено; при возвращении
  из настроек книга перевёрстывается с сохранением позиции чтения (§2.8)
- яркость: вертикальный свайп по правому краю экрана; своя яркость приложения, системная и автояркость не влияют
- тема: как в системе / день / ночь
- листание: страницы / прокрутка. При прокрутке главы идут лентой, ядро рисует их полосами,
  касание в верхней или нижней трети экрана и кнопки громкости сдвигают текст на экран;
  центр открывает меню, как в режиме страниц

## 5. Этапы

| Этап | Результат |
|------|-----------|
| M0 | Окружение: Rust, JDK, Android SDK + NDK, cargo-ndk; устройство с отладкой по USB |
| M1 | Ядро на компьютере: FB2 → модель → типограф → шейпинг → переносы → Кнут — Пласс → страницы → PNG. Сравнение со скриншотами Kindle |
| M2 | EPUB (2 и 3), подмножество CSS, картинки, сноски, оглавление |
| M3 | Android: экран чтения, жесты, строка статуса, темы, сохранение позиции. **Первая версия на телефоне** — раньше M2 |
| M4 | Библиотека, импорт, папка шрифтов, фоновая раскладка книги, проценты |
| M5 | Шлифовка: висячая пунктуация, производительность, разбор всех случаев из корпуса |

## 6. Открытые вопросы

- Скриншоты Kindle тех же страниц для калибровки полей, кегля и интервала — если есть Kindle под рукой.
