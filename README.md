# BookWorm

Читалка FB2 и EPUB для Android с собственным движком вёрстки на Rust: разбор книги, типограф, переносы
по словарям, вёрстка по алгоритму Кнута — Пласса, страницы на сетке строк. Android только показывает
готовые пиксели. Эталон типографики — электронная книга Kindle. Интерфейс на русском.

- `crates/core` — ядро (`bookworm-core`): FB2/EPUB → страницы. Собирается и тестируется на компьютере.
- `crates/bw-render` — книга → PNG-страницы, как их сверстает читалка.
- `crates/android` — JNI-мост к приложению.
- `android/` — приложение на Kotlin без AndroidX: библиотека, читалка, настройки, сведения о книге.
- `fonts/` — встроенные шрифты (SIL OFL), `tools/` — сборка APK и генератор тестового корпуса.
- `docs/SPEC.md` — спецификация и принятые решения, `docs/STATUS.md` — текущее состояние.

## Сборка

```
cargo test -p bookworm-core --release                  # тесты ядра
cargo run --release -p bw-render -- tests/corpus/synthetic/02_structure_ru.fb2 --pages 1-3
ABIS=arm64-v8a tools/build_apk.sh                      # нужны Android SDK + NDK, cargo-ndk, Gradle
```

В настройках можно включить бионическое чтение: начальная треть каждого слова выделяется
более плотным начертанием. Для просмотра на компьютере добавьте `--bionic` к команде `bw-render`.

Долгое нажатие на абзац → выделение фрагмента → «Описать ошибку» сохраняет TXT-промпт
с комментарием и данными для воспроизведения ошибки оформления. В сведениях о книге можно
отметить её прочитанной; фильтр библиотеки скрывает отмеченные книги.

APK получается в `out/BookWorm.apk` (подписан отладочным ключом). Книг в приложении и в репозитории нет:
добавляйте свои файлы кнопкой «+» или через «Поделиться».
